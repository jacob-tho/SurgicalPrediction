# Prediction of Surgical Complications Using Machine Learning

Dieses Projekt untersucht verschiedene Machine-Learning-Ansätze zur Vorhersage der Zielvariable **Surgical Complication** auf Basis medizinischer Patientendaten. Neben der reinen Modellperformance liegt ein besonderer Fokus darauf, herauszufinden, welche Merkmale besonders aussagekräftig für postoperative Komplikationen sind.

## Projektziel

Ziel des Projekts ist es, anhand medizinischer Features vorherzusagen, ob bei einem chirurgischen Eingriff eine Komplikation auftritt. Dafür werden mehrere Machine-Learning-Modelle trainiert, evaluiert und miteinander verglichen.

Zusätzlich wird analysiert, welche Features den größten Einfluss auf die Vorhersage haben. Dadurch soll das Projekt nicht nur eine möglichst gute Klassifikationsleistung erzielen, sondern auch interpretierbare Erkenntnisse über relevante Risikofaktoren liefern.

## Fragestellung

Die zentrale Fragestellung lautet:

> Können postoperative chirurgische Komplikationen anhand vorhandener medizinischer Patientendaten zuverlässig vorhergesagt werden?

Daraus ergeben sich weitere Teilfragen:

- Welche Machine-Learning-Modelle eignen sich am besten für diese Klassifikationsaufgabe?
- Welche Features sind besonders relevant für die Vorhersage von Surgical Complications?
- Wie unterscheiden sich die Modelle hinsichtlich Genauigkeit, Robustheit und Interpretierbarkeit?
